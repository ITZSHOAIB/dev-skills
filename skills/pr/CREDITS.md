# Credits

This skill is a fork of [Matt Pocock](https://github.com/mattpocock)'s [`pr`](https://github.com/mattpocock/skills/tree/main/skills/engineering/pr) skill (MIT). The fork adds the **Special things to note** section, which [`guided-review`](../guided-review/SKILL.md) relies on to tell deliberate omissions from defects.

The **Summary** section's menu of visuals (pseudocode, call trees, component trees, file trees, Mermaid, diffs) and its placement guidance come from [Dex Horthy](https://github.com/dexhorthy)'s [`show-me`](https://github.com/humanlayer/skills/tree/main/plugins/show-me) skill, reproduced almost word for word and aimed at a diff instead of a live conversation. `pr` does not depend on `show-me` as a skill (a hard dependency would break standalone installs), so the content is copied in rather than pointed at; this file is the attribution a dependency would otherwise have carried.

The **Special things to note** section comes from the PR description template in HumanLayer's [`visual-pr`](https://github.com/humanlayer/skills/tree/main/plugins/visual-pr) skill (MIT).
